# 🍢 Global Sosis Haurgeulis

Project website company profile yang dibuat oleh Subhan Ashof untuk **Global Sosis Haurgeulis** — Distributor produk olahan frozen food sosis, nugget, dan olahan bakso premium dari Haurgeulis, Indramayu, Jawa Barat.

🌐 **Live:** [globalsosishgl.biz.id]

---

## Tech Stack

| Teknologi | Keterangan |
|-----------|------------|
| React + Vite | UI library & build tool |
| TypeScript | Type-safe development |
| Tailwind CSS | Utility-first styling |
| Lucide React | Icon library |
| Vercel | Hosting & deployment |

---

## Fitur

- **Multi-category Product Catalog** — kategori Sosis Premium, Nugget Crispy, dan Olahan Bakso dengan filter interaktif
- **WhatsApp Order Integration** — tombol order langsung terhubung ke WhatsApp
- **Google Maps Embed** — lokasi toko terintegrasi di halaman kontak
- **Responsive Design** — tampilan optimal di desktop dan mobile
- **Editable Articles** — konten artikel/media yang dapat dikelola langsung dari data
- **Smooth Navigation** — animated header, mobile dropdown toggle, smooth scroll antar section

## Instalasi & Menjalankan Lokal

```bash
# Clone repo
git clone https://github.com/hanz13/globalsosishgl.git
cd globalsosishgl

# Install dependencies
npm install

# Jalankan dev server
npm run dev
```

Buka [http://localhost:5173](http://localhost:5173) di browser.

---

## Build & Deploy

```bash
# Build untuk production
npm run build

# Preview hasil build
npm run preview
```

Deploy otomatis ke **Vercel** setiap push ke branch `main`.
